# Design Patterns Learning Portal

Este projeto é um portal interativo para o aprendizado de padrões de projeto (Design Patterns).

## Visão Geral
O objetivo é transformar a experiência de aprendizado, movendo-se de uma lista estática de patterns para um fluxo de evolução natural.

## Estrutura do Projeto
- **Sidebar (Esquerda):** Menu com o índice dos 27 conceitos e patterns.
- **Área Central:** Explicação teórica e exemplos de código.
